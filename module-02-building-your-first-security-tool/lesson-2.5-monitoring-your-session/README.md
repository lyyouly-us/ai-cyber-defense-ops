# Lesson 2.5 – Monitoring Your Session

## Objective

Learn how to monitor Claude Code's context usage and manage long development sessions.

## Completed

- Checked the current session context using `/context`.
- Reviewed token usage and context breakdown.
- Learned when to use `/compact`.
- Understood how context management helps maintain Claude's performance during long coding sessions.

## Commands Used

```text
/context
```

Optional:

```text
/compact Keep the current parser.py implementation and summarize everything else.
```

## What I Learned

Claude Code has a limited context window. As conversations grow, token usage increases. Monitoring context helps prevent the model from losing important project information.

## Why This Matters

Large software projects often involve long conversations with an AI assistant. Managing context ensures important design decisions, code, and documentation remain available throughout the session.

## Professional Takeaway

Effective AI-assisted development involves more than writing prompts. Monitoring context usage and preserving critical information helps maintain consistency and improves the quality of long-running development sessions.

## Career Connection

Large AI-assisted software projects often span hundreds of prompts. Understanding how to monitor and manage an AI assistant's context is an increasingly valuable skill for developers, security engineers, and AI practitioners 
who use coding assistants in professional environments.
